# Brand Engine Integration

Brand Engine is an operational automation layer.

```text
Signal
→ target discovery
→ decision-maker discovery
→ qualification
→ CRM
→ research
→ content/outreach
→ conversation
→ meeting
→ opportunity
```

HarvyX/Brand Engine feeds the CRM.

CRM remains the commercial system of record.

External tools are integrations, not core domain ownership.
