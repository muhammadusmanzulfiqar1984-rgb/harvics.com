## Controlled execution

```text
Domain data
→ feature/read model
→ AI model
→ structured decision
→ governance
→ human approval if required
→ domain action
→ audit
```

AI must not execute arbitrary SQL, bypass permissions, bypass governance or move money directly.

The Board Briefing says the complete eight-model engine is not currently operating as specified; do not claim it is live without repository evidence.
