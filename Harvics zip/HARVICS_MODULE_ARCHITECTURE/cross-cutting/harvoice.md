# Harvoice

The Soul specification describes Harvoice as a voice interface built on Gemini Live API with 16kHz PCM16 audio and secure session/token handling.

```text
Microphone
→ secure session
→ speech understanding
→ intent
→ typed command
→ permission
→ validation
→ governance
→ domain API
→ result
→ voice response
```

Harvoice is not a generic chatbot.

Long-lived provider credentials never enter the browser.
